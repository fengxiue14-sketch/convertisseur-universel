# Convertisseur Universel

Troisieme projet de la **Forteresse YUAN**.

## Objectif

Creer un convertisseur interactif en Python couvrant 6 categories d'unites :

- Longueurs (m, km, cm, mm, miles, pieds, pouces, yards)
- Masses (kg, g, mg, tonnes, livres, onces)
- Temperatures (Celsius, Fahrenheit, Kelvin)
- Temps (secondes, minutes, heures, jours)
- Volumes (L, mL, m3, gallons, pintes)
- Devises (EUR, USD, XOF, GBP)

## Installation

Aucune dependance externe. Python 3.10+ requis.

## Usage

Lancer le script :

    python convertisseur.py

Puis naviguer dans les menus numerotes.

## Exemples de conversion

| Entree | Sortie |
|--------|--------|
| 100 km -> miles | 62.1371 miles |
| 100 degC -> degF | 212.0000 degF |
| 100 EUR -> XOF | 65595.70 XOF |
| 1 kg -> livres | 2.20462 livres |

## Competences acquises

- Dictionnaires imbriques
- Menus interactifs numerotes
- Refactoring (fonction generique reutilisable)
- Cas speciaux (temperature differente)
- Formatage de nombres (precision)
- Gestion d'erreurs robuste
